# 常见问题

## 找不到本地服务：Specified native messaging host not found

从 Windows 文件资源管理器双击项目的 install.cmd，然后重新加载扩展。安装脚本和浏览器应由同一个 Windows 用户运行，无需管理员权限。

部分打包桌面应用会隔离它启动的安装进程的文件或注册表写入。曾出现从 Codex 内安装可在其测试环境连接、日常 Edge 却找不到服务的情况。因此应从普通文件资源管理器启动安装，而不是只依赖嵌入式终端的成功提示。

## “未知操作”

通常是扩展与本地服务不匹配。请使用同一发布包中的文件；等待归档完成，关闭扩展，从文件资源管理器运行 install.cmd，再启用并重新加载扩展、重新打开管理页。

## 浏览器内置页面提示不允许使用扩展

新标签页和浏览器设置页面限制扩展操作页面内容。下载驿站不需要读取这些页面；通过工具栏打开扩展即可。此提示不等于本地服务连接失败。

## 下载去了与浏览位置不同的文件夹

浏览文件夹不会改变目标，必须点击“将下载保存到此文件夹”。顶部显示生效位置。

使用“浏览器当前下载目录”类型时，所选根目录必须与浏览器设置一致。工具不会替你修改浏览器默认位置。若需要明确指定任意绝对路径，选择“自定义目录”。

## 搜索不完整或目录未显示

搜索上限约为 10000 个目录、500 次分页请求及 32 层。权限限制、目录链接或扫描上限会显示不完整提示。隐藏名称、不支持的 Windows 名称、目录链接和 DownloadPort 暂存目录不会作为普通分类展示。

外部修改目录后刷新当前层。分页读取不是文件系统快照，目录在读取期间变化时可能需要重新刷新。没有搜索结果不应被理解为文件本身不存在；工具只搜索文件夹。

## 归档失败

在“更多”的下载记录查看错误，检查目标盘是否连接、空间及权限。原始下载会保留在浏览器下载目录的 DownloadPort/incoming 下。排除原因后重试；不要在任务运行时手动清理暂存文件。

## 提交问题时

请提供扩展版本、本地服务版本、浏览器版本、目录类型和复现步骤。截图前遮挡个人路径、文件名等信息。不要上传任务数据库、整个浏览器配置或真实下载文件。
