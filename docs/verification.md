# 验证范围

发布版本：1.0.0。测试使用生成的样本，不使用用户真实下载文件。

- Windows / Python 3.12：22 项测试，包括真实原生进程通信、复制归档、重名竞争、并发、故障恢复、源文件改变、目录边界、只读取一层及分页。
- Node.js 24：14 项测试，包括配置兼容、路径验证、仅下一次并发消费、显式目录选择优先级、后台删除和权限边界。
- 独立 Edge 配置：逐层浏览、浏览不改变目标、确认后下载、路径导航、全目录搜索、48 像素行高、600 像素弹窗底部可见、仅下一次真实下载归档、更多/返回。

故障恢复使用 verified、committed、source_removed 等阶段注入故障，不是物理断电测试。未完整验证 NAS、移动硬盘拔出、超大文件、企业策略或所有 Chrome/Edge 版本。

日常浏览器安装必须另行验证。打包桌面应用可能隔离安装环境，因此独立测试通过不代表用户浏览器已经注册成功。安装应从 Windows 文件资源管理器运行。
